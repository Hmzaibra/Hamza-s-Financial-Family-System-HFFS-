{# Deliberately not extending base.html, for two reasons. The service worker stores this page at install time, cookie and all, so anything the layout puts on it — the signed-in name, the tab bar, a flash message — would be frozen into a file that is then shown to whoever picks up the phone next, possibly weeks later. A page that outlives its session should not carry one. And this is the one page in the app that has to render when the server does not answer, so it depends on nothing: no context processor, no session, no JavaScript. One stylesheet, which the worker caches beside it. #}
